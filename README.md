# Messenger

Учебный мессенджер для Яндекс Практикума: авторизация, регистрация, список чатов, переписка и профиль. Интерфейс собран на TypeScript, Vite, Handlebars и Sass.

**Ссылка на netlify:** [https://shiny-lamington-3d97f7.netlify.app/](https://shiny-lamington-3d97f7.netlify.app/)

## Требования

- Node.js
- npm

## Установка

```bash
npm install
```

## Запуск

Режим разработки (Vite, `--host`):

```bash
npm start
```

## Сборка

Проверка типов и production-сборка:

```bash
npm run build
```

Просмотр собранного проекта локально:

```bash
npm run preview
```
